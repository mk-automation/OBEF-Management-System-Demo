# OBEF Management System – GitHub Pages Demonstration

Interactive static prototype of an Outcome-Based Evaluation Framework (OBEF) management system.

## Demo scope
- Executive dashboard
- 6 OBEF pillars
- 24 institutional KPIs
- 22 program KPIs
- KPI data-entry demonstration using browser localStorage
- Evidence repository metadata demonstration
- KPI 2.1 assessment-quality review
- Improvement actions and Closing the Loop
- Future Readiness
- Management report, print/PDF and CSV export
- User management and audit-log prototype

## Important
This repository is a **demonstration/prototype**, not a production information system.
GitHub Pages is static hosting. Do not place confidential institutional data, real credentials, student records, or sensitive evidence in this demo.

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Click **Save**.
6. Wait for GitHub to publish the site.
7. Open the URL shown by GitHub Pages.

Framework reference: MoHESR OBEF University Guide Version 11.5 (23 March 2026).
